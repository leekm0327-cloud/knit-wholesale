# 자동 오퍼리스트

관리자 **영업·거래처 → 오퍼리스트**, 또는 **상품 관리 → 오퍼리스트**에서 사용한다.

- 판매중(`available=1`)이며 노출 카테고리에 속한 상품을 현재 상품/카테고리 순서로 구성한다. 품절·숨김/미분류·상품명 없는 항목은 제외하고 개수를 표시한다.
- 기본 도매가(`products.price`)이며 **부가세 별도**, 상품명에 적힌 중량/포장 단위 그대로다. 원가·공급처 코드·거래처별 약정가는 출력하지 않는다.
- 원산지·향미·가공·품종·로스팅·최소수량은 등록된 값만 사용한다. 세부 정보가 없어도 상품은 포함한다. 잘못된 가격은 ‘가격 확인 필요’, 실제 0원은 ‘0원’으로 표시한다.
- 페이지 진입/다시 활성화/최신 상품 반영 시 조회한다. 글 복사·인쇄 직전에 다시 조회하고 목록/정보가 바뀌었으면 미리보기부터 갱신해 사용자가 다시 확인하게 한다. 조회 실패 시 오래된 목록을 내보내지 않는다.
- **글 복사**는 메시지용 텍스트, **인쇄 / PDF 저장**은 현재 미리보기를 브라우저 인쇄 화면으로 보낸다. PDF로 저장을 선택한다. 도매가 표시를 끄면 두 출력 모두 가격이 빠진다.
- 파일/복사본은 생성 시점의 자료다. 이후 품절·가격 변경 시 사이트에서 다시 생성해야 한다. 자동 발송은 없다.
- `GET /api/admin/offer-list`는 관리자 전용·캐시 금지·읽기 전용이다. DB 스키마, 상품·주문·장부 데이터는 변경하지 않는다.

검증: `node --import tsx script/tests/offer-list.test.ts` (가짜 상품과 임시 HTTP 서버만 사용).
