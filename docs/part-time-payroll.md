# 파트타이머 급여 (운영 미배포)

근태현황에 소유자 전용 급여 패널을 추가했다. 실제 직원 계약과 시급은 등록하지 않았다.

## 사용 흐름
1. 직원과 급여 월을 선택한다. 정산 기간은 매월 1일~말일이다.
2. 계약 시작·종료일, 요일별 출퇴근, 무급 휴게시간, 시급(주휴 별도), 주휴 요일과 사업장 규모를 등록한다.
3. 기본 급여는 계약시간으로 계산한다. 11:15~14:40 기록 / 11:30~14:30 계약이면 180분이며 추가 실제 근무 여부를 소유자가 확인한다.
4. 지각·조퇴·결근·휴가·근무표 불일치 등은 자동 차감하지 않는다. 일별 급여시간과 개근 판단을 사유와 함께 저장한다. 실제 근무한 계약 외 시간은 누락하지 않는다.
5. 주휴 요건, 추가 지급·공제액을 검토하고 월 종료 후 확정한다. CSV를 내려받을 수 있다.

## 계산 범위와 제한
- 고정된 계약이 유지된 4주 구간의 평균 주 소정근로시간 15시간 이상과 해당 주 개근을 기준으로 주휴수당을 계산한다. 지각·조퇴 자체를 결근으로 처리하지 않는다.
- 주휴시간은 4주 총 소정근로시간 / 비교 통상근로자의 4주 소정근로일수. 주휴일이 속한 달에 배정하고 이전 달 근태도 읽는다.
- 입사 초기, 계약 변경, 주 전체 휴가, 종료 주는 소유자 검토가 필요하다. 종료일 뒤 주휴일은 자동 생성하지 않으므로 종료 주 미정산 수당을 추가 지급으로 검토한다.
- 상시 5인 이상 단시간근로자 계약초과시간 50% 가산을 자동 계산한다. 적용 사업장·근로자 구분을 먼저 확인해야 한다.
- 야간·휴일·유급 공휴일 및 기타 수당은 소유자가 확인한 추가 금액으로 입력한다. 알림 설정의 공휴일 목록을 사용하므로 공휴일 자료의 완전성을 별도로 확인한다.
- 세금·4대보험·퇴직금 자동 산정과 송금은 포함하지 않는다. 확인된 공제액만 입력한다.
- 최저임금 검사는 2026년 10,320원만 내장되어 있다. 다른 연도는 확인 안내가 표시된다.
- 기본급과 주휴수당은 각각 월 합계 원 미만 올림. 일별 자동 가산은 원 미만 올림.

## 보존·접근
- 소유자 권한을 모든 급여 API에서 검사한다.
- 출퇴근·근무표 원본을 수정하지 않는다. 급여 계약·결정·변경 전후·사유·작업자를 별도 테이블에 보존한다.
- 계약·근태 원본이 달라지면 확인과 확정 상태를 무효화하고 재검토한다. 퇴근 수정 승인 대기가 있으면 월 확정을 차단한다.
- 시급 변경은 기간이 겹치지 않는 새 계약으로 추가하여 과거 계산을 보존한다.

## 확인 결과
- 독립 메모리 DB API 테스트: 계약시간, 소유자 예외, 주휴 기준, 월 경계, 5인 이상 추가시간, 수정 이력, 원본 변경 무효화, 접근 제한, 원본 보존 통과.
- 클라이언트·서버 빌드 통과. 기존 TypeScript 진단 35건과 동일하며 새 진단 없음(행 번호 이동 제외).
- 가상 직원 브라우저에서 9월 선택, 일별 180분 확인 저장, 주휴 재계산, 확인 필요 0건 확인.
- 로컬 미리보기: script/preview-payroll.ts, 포트 8772. 운영 DB·외부 발송과 분리.
