# 통장 내역 검토 — 테스트 버전

관리자 재무 메뉴의 `통장 내역 · 테스트`에서 사용한다. 대표 계정만 접근 가능하다.

## 서버 설정

- BAROBILL_TEST_KEY: 테스트 연동인증키
- BAROBILL_CORP_NUM: 사업자번호 숫자 10자리
- BAROBILL_USER_ID: 바로빌 테스트 회원 아이디

인증키는 서버 환경변수에만 설정한다. 운영서버 주소나 운영키는 사용하지 않는다.

## 동작

입출금을 모두 수집하며 바로빌 거래 식별번호와 계좌로 중복을 방지한다.
전체 데이터를 받아 검증한 뒤 한 트랜잭션으로 저장하므로 조회 도중 실패하면 부분 저장하지 않는다.
기존 비용·수금은 같은 금액과 거래일 전후 7일 기준으로 후보를 표시한다.
거래처 연결 후보, 카드대금, 계좌 간 이동, 대출 관련, 기타 분류와 메모를 저장할 수 있다.
분류는 미확인으로 되돌릴 수 있다. 기존 비용/수금 기록은 중복 연결을 차단한다.
테스트 검토 저장은 expenses/payments와 외상매출금에 영향을 주지 않는다.

## 검증

2026-09-08 테스트 API 조회: 376건, 입금 331건, 출금 45건, 고유 거래 식별번호 376개.
화면에 제공된 376건과 총건수 일치. 은행 원장 및 ECOUNT 금액 대조는 아직 하지 않았다.
메모리 DB 테스트: 대표 권한, 계좌 마스킹, 연결 후보, 중복 연결 차단, 연결 해제, 장부 보존, 수집 재실행 중복 방지 통과.
배포 빌드 통과. 전체 타입 검사는 기존 다른 화면의 오류가 남아 있다.

## 후속 범위

운영 배포/운영키 설정, 비용 신규 생성, 실제 수금 처리, 입금자 매핑 자동 적용, 부분·합산 결제,
카드 구매 내역별 대조는 별도 구현 및 검증이 필요하다. 이 버전에서 자동 장부 반영하지 않는다.

## 비용·수금 반영 테스트 추가

통장 검토 하단에서 비용 항목/사업 부문 또는 수금 거래처를 선택하고 중복 여부 확인 후 테스트 장부에 반영한다.
입력 금액은 통장 금액으로 고정한다. 동일 반영 재요청은 기존 결과를 반환하며 다른 조건으로 재요청하면 거절한다.
기존 장부 연결, 카드대금, 계좌 간 이동, 대출 분류는 신규 반영을 차단한다.
비용 항목은 활성 원가·판관비 항목만 허용한다. 대출 원금 및 비용 아닌 항목은 직접 비용화하지 않는다.
반영 후 분류 변경은 차단하며 취소 사유 입력 후 취소할 수 있다. 취소 이력과 행위자/시간은 보존한다.
테스트 장부 요약은 취소되지 않은 비용 합계와 거래처별 수금 차감 예정액을 표시한다.

bank-posting.test.ts: 권한, 입출금 방향, 비용 항목, 중복 확인, 반복 요청, 수정 충돌, 취소 재요청,
교차 내역 취소 방지, 집계 복원, 감사 기록, 운영 expenses/payments 불변을 검증했다.
운영 장부 반영 및 자동 매핑은 아직 활성화하지 않았다. 운영 배포도 수행하지 않았다.
