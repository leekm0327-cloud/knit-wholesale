# 추출 기록과 파트너 가이드

## 직원 입력

- 향미 선택은 접힌 상태로 시작한다. 검색, 분류 선택, 직접 추가를 지원한다.
- 같은 향미의 표기 차이(초콜렛/초콜릿, 카라멜/캐러멜 등)를 하나로 저장한다. 한 기록에 최대 20개, 향미 이름은 30자까지 입력한다.
- 기본 항목은 산미·단맛·바디·쓴맛이다. 강도와 품질을 독립적으로 입력한다.
- 미평가의 저장값은 null이다. 산미·단맛·쓴맛의 강도는 0(없음)도 선택할 수 있다. 나머지는 1~5다.
- 향미, 후미 길이/품질, 균형, 깔끔함, 질감, 아쉬운 특성, 기존 종합 평가와 메모는 ‘상세 평가 · 메모’ 안에 있다.
- ‘이 세팅을 파트너 권장 레시피로 공유’는 기본 해제다. 공유하려면 도징·추출량·시간이 모두 0보다 커야 한다.
- 직전 세팅 불러오기는 기존대로 레시피 값만 복사한다. 향미, 감각 평가, 공유 선택은 복사하지 않는다.

## 파트너 조회

- 주문 카탈로그와 `/#/espresso`에서 같은 가이드를 사용한다.
- 원두를 고르면 권장 레시피, 최근 대표 향미 최대 5개, 기본 네 항목의 평균 강도가 보인다.
- 최근 14일은 한국 시간 기준 오늘을 포함한 14개 달력 날짜다. 미래 날짜는 제외한다.
- 향미 빈도는 기록별로 한 번씩 계산한다. 강도는 항목별 평가 건수를 분모로 삼고, null은 제외하며 0은 포함한다.
- 공유를 선택한 유효 레시피 중 기록일/작성 시각이 가장 최근인 것을 권장으로 쓴다. 최근 14일 밖의 권장 세팅은 날짜와 ‘이전 기록’을 표시한다.
- 새 권장 세팅이 없으면 이전 양식의 긍정 평가 중 최신 유효 세팅을 ‘기존 참고 레시피’로 표시한다. 이전 기록을 새 감각 평가로 환산하지 않는다.
- 상세를 펼치면 집계 기간·항목별 건수·최소/최대, 전체 향미 빈도와 추출 환경/기록을 볼 수 있다.
- 공개 응답은 필요한 필드만 포함한다. 직원 이름, 내부 메모, 품질, 상세 평가, 아쉬운 특성은 전송하지 않는다. 기존 통계 API에서도 내부 메모를 제외했다.

## 저장 및 검증

`espresso_logs`에 nullable `sensory` JSON과 기본 0인 `recommend_to_partners`를 추가한다. 기존 행의 메모·향미·점수는 변경하지 않는다. 직원/관리자 조회에서는 새로운 내부 평가를 펼쳐 확인할 수 있다.

`node --import tsx script/tests/espresso-sensory.test.ts`는 향미 정규화, 점수 검증, 한국 시간 경계, 미평가/0 집계, 추천 선택, 공개 필드 분리 및 임시 SQLite DB에서 기존 스키마 업그레이드와 저장/조회/삭제를 확인한다. 테스트 데이터는 자체 생성한 임시 폴더에만 저장한다.

추가로 로컬 서버에서 직원 로그인 → 실제 폼 입력 → 저장 → 재접속 → 파트너 조회를 검증했다. 비로그인 저장과 타 직원의 기록 삭제는 거부되었으며, 390px/1280px에서 화면을 확인했다. 빌드 성공; 프로젝트의 기존 TypeScript 오류 35건에 추가 오류 없음.
